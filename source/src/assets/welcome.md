## 为什么值得用

### 阅读体验更完整

- **渲染更标准，格式不跑偏**：完全对照 [GitHub Flavored Markdown Spec](https://github.github.com/gfm/) 官方规范逐场景适配。同一份样例文档对比导出后，在软换行、跨行标题、跨行链接定义、非法邮箱自动链接等细节上，Folio 的渲染结果更贴近官方标准；主流商业软件仍存在多处可见的格式偏差。
- **文件夹即书库，阅读体验完整**：文件目录树、文档大纲、章节跳转、阅读进度记忆、多标签页、前进后退导航，整套阅读能力一应俱全，浏览长文档不迷路。
- **全文搜索，定位精准**：支持全库全文检索，短至一两个字的中文关键词也能正常匹配；点击搜索结果直接跳转到对应段落。
- **纯本地运行，隐私全可控**：所有数据仅保存在本机，无需登录、不上传文件、无遥测数据收集，文档安全有保障。

### 写作与整理更顺手

- **读编一体，切换顺滑**：按 `Ctrl+E` 即刻进入编辑，任务列表可直接勾选交互，`Ctrl+S` 一键保存，无需在阅读与编辑模式间反复切换。
- **不用背语法，上手零门槛**：右键菜单可快速插入表格、代码块、提示块、Emoji 表情；内置 57 个常用表情，点选即可插入，不用记忆 Markdown 语法。
- **一键整理，格式规范化**：按 `Shift+Alt+F` 自动格式化 Markdown 源码，按 `F2` 快速重命名文件或文件夹，批量整理文档更高效。
- **导出即用，格式完整保留**：支持一键导出 HTML 与 PDF，图片、表格、脚注、目录书签均可完整带出，导出文件可直接分发分享。

## 30 秒快速上手

1. **打开文件**：按 `Ctrl+O` 打开单个 Markdown 文件，也可直接将文件拖入窗口。
2. **打开书库**：选择「文件 → 打开文件夹…」，把整个目录当作一本书来浏览。
3. **快速定位**：点击左侧大纲快速跳转章节；按 `Ctrl+F` 搜索内容；按 `Alt+↑` / `Alt+↓` 切换上一章 / 下一章。
4. **修改保存**：按 `Ctrl+E` 进入编辑模式，修改完成后按 `Ctrl+S` 保存。
5. **导出分享**：从「文件」菜单导出 HTML 或 PDF，即可直接分享。

> [!TIP]
> 最常用的三个动作：`Ctrl+F` 搜索、`Ctrl+E` 编辑、`Ctrl+S` 保存。熟悉这三组按键后，大多数阅读与修改任务都能完成。

## 推荐先体验的功能

| 体验一下 | 可以观察什么 |
| :--- | :--- |
| 打开一个项目文档文件夹 | 通过大纲在「安装 → 配置 → 使用」章节间快速跳转 |
| 搜索一个中文关键词 | 点击搜索结果直接定位到对应段落 |
| 勾选一个任务列表项 | 保存后查看源码中 `[ ]` 是否自动变为 `[x]` |
| 格式化一份格式杂乱的 Markdown | 按 `Shift+Alt+F` 查看整理效果，再按 `Ctrl+Z` 撤销对比 |
| 导出一份 PDF | 检查目录书签、表格与图片是否完整保留 |
