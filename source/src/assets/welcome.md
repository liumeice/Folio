# 欢迎使用 Folio

Folio 把本地 `.md` 文件当成「书」来读：打开即读、大纲导航、记住读到哪、全文搜索。

## 从这里开始

- 按 `Ctrl+O` 打开一个 Markdown 文件，或直接把文件**拖进窗口**
- 用菜单「文件 → 打开文件夹…」打开整个文档目录（同一时间只打开一个文件夹，再选一个就是切换）
- 按 `Ctrl+F` 搜索（默认只搜当前文档，点右上角可切到全部文档）；`Alt+←/→` 后退前进；`Alt+↑/↓` 上一章 / 下一章
- 左侧栏三个面板：**文件夹**（所选文件夹的目录层级，来自「打开文件夹…」）· **最近打开**（打开记录）· **大纲**
- `Ctrl+E` 进入编辑（已开启行号和高亮），`Ctrl+S` 保存、`Esc` 放弃修改

## 阅读状态

每篇文档单独记住阅读位置（所在章节 + 段内位置），切走再回来仍从上次的位置继续。
工具栏的滑杆按钮打开**排版设置**：字号、行高、字距、段距、对齐、行宽、代码字号与表格密度，
改完立即生效并自动保存，重启后仍然保留。
