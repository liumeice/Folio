# 欢迎使用 Folio

Folio 把本地的 `.md` 文件当成「书」来读：打开即读、大纲导航、进度记忆、全文检索。

## 从这里开始

- 按 `Ctrl+O` 打开一个 Markdown 文件，或直接把文件**拖进窗口**
- 用菜单「文件 → 打开文件夹…」登记你的整个文档目录（同时只开一个库，再选一个目录就是切换）
- 按 `Ctrl+F` 检索（默认当前文档，芯片可切到「全部已登记」）；`Alt+←/→` 前进后退；`Alt+↑/↓` 翻章节
- 左侧栏三个面板：**文件夹**（展示所选文件夹的目录层级，来自「打开文件夹…」）· **最近打开**（打开历史）· **大纲**
- `Ctrl+E` 进入编辑（行号与语法着色已就绪），`Ctrl+S` 保存、`Esc` 放弃

## 阅读状态

每个文档独立记忆阅读位置（标题锚点 + 段内偏移），切走再回来仍从上次的位置继续。
工具栏的滑杆按钮打开**排版设置**抽屉：字级、行高、字距、段距、对齐、行宽、代码块字号与表格密度，
底部带实时样张与「恢复默认」，所有偏好自动写入 SQLite，重启仍在。

> 不需要时可以在历史里移除这条记录（文件本身仍留在应用数据目录）。
