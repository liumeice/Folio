# Folio 使用指南

**适用版本**　`0.2.1.134`　·　**更新日期**　2026-11-23

Folio 是一款 Windows 桌面端本地 Markdown 阅读器。打开一个文件夹，即可将其中的 Markdown 文档作为完整书库浏览；需要修改内容、勾选任务、插入表格或导出分享时，无需跳转其他工具，在当前文档内即可完成全部操作。

> [!NOTE]
> 本文档同时作为应用内置指南与仓库官方使用说明。它不会显示在文件夹目录树中，仅出现在「最近打开」列表；与普通文档一致，支持阅读、编辑与全文搜索。

## 1. 5 分钟快速上手

第一次使用只需完成五步：打开书库、选择文档、定位内容、编辑保存、导出分享。先跑通基本流程，再按需深入后面的功能。

### 1.1 首次使用引导

1. **打开书库**：点击「打开文件夹」，选择本地 Markdown 文档目录（例如 `D:\notes`）。
2. **选择文档**：左侧将自动生成目录树，点击任意 `.md` 文件即可开始阅读。
3. **定位内容**：通过左侧大纲面板快速跳转章节；按 `Ctrl+F` 唤起全文搜索。
4. **修改保存**：需要修改内容时按 `Ctrl+E` 进入编辑态，修改完成按 `Ctrl+S` 保存。
5. **导出分享**：需要分享时，通过「文件」菜单一键导出 HTML 或 PDF 文件。

> [!TIP]
> 如果只想先读、不做修改，完成第 1–3 步即可；第 4–5 步可在需要编辑和分享时再使用。

### 1.2 高频操作速查

| 操作目标 | 实现方式 |
| :--- | :--- |
| 按目录浏览系列文档 | 选择「打开文件夹」→ 点击左侧目录树 |
| 快速回到已读文档 | 左侧「最近打开」面板 |
| 跳转指定章节 | 点击左侧大纲，或按 `Alt+↑` / `Alt+↓` |
| 检索关键词 | `Ctrl+F` 或 `Ctrl+K` |
| 修改内容 / 勾选任务 | `Ctrl+E` 进入编辑；任务项可直接点击勾选，完成后按 `Ctrl+S` |

## 2. 阅读：文件夹书库、最近打开与多页签

本章说明文件夹书库与「最近打开」的区别，以及多页签和阅读辅助功能的使用方式。

### 2.1 打开文件夹与最近打开的区别

二者是独立功能，使用场景与逻辑互不影响：

| 维度 | 打开文件夹 | 最近打开 |
| :--- | :--- | :--- |
| 核心用途 | 按目录结构批量浏览一组文档 | 快速回溯历史打开过的文档 |
| 触发方式 | 手动选择文件夹并完成扫描 | 任意一次打开文档的行为都会自动记录 |
| 内容范围 | 所选文件夹及子目录下的全部 Markdown 文档 | 所有打开过的文档，不受目录限制 |
| 相互影响 | 单独打开文件不会加入当前目录树 | 保存文档不会改变其所属目录树 |

> [!NOTE]
> **场景示例**：先打开 `D:\notes` 作为书库，再单独打开 `D:\tmp\a.md`。此时 `a.md` 会出现在「最近打开」列表，但不会加入 `D:\notes` 的目录树中。

补充说明：

- 同一时间仅支持一个打开的文件夹；开启新文件夹会替换当前书库。
- 打开文件夹仅执行读取与扫描，不会修改、移动或复制源文件。
- 支持打开 `.md`、`.markdown`、`.txt` 格式；单次批量打开上限为 100 个文件。
- 文档读取兼容 UTF-8、GBK/GB18030、UTF-16 LE/BE 编码；保存时按原编码回写，状态栏可查看当前编码格式。

### 2.2 多页签管理

- 打开新文档将自动新增页签；同路径文档重复打开仅激活已有页签，不会重复创建。
- 点击页签即可切换；可通过 `Ctrl+W`、鼠标中键或页签关闭按钮关闭页签。
- 关闭最后一个页签后将回到空白界面，不会删除磁盘文件或清空最近打开记录。
- 存在未保存修改的页签会显示脏标记，关闭前将弹出确认提示。
- 文件重命名后，对应页签会自动同步新路径，不会产生重复页签。

### 2.3 阅读辅助功能

- `Ctrl+滚轮`：放大 / 缩小阅读区正文字号。
- `Home` 键：快速回到文档开头；`Alt+↑` / `Alt+↓`：切换上一章 / 下一章。
- 代码块右上角内置复制按钮，同时显示对应语言标签。
- 单张图片默认居中显示；连续多张图片将自动形成图片行，保持横向排列。
- 外部链接将调用系统默认浏览器打开，不会在 Folio 主窗口内跳转网页。
- 每次关闭文档都会自动保存阅读位置；下次打开时默认回到上次浏览处。

## 3. 定位：大纲导航、全文搜索与阅读进度

长文档不必从头翻找。大纲、全文搜索和阅读进度分别解决「按结构找」「按关键词找」和「回到上次位置」三类需求。

### 3.1 大纲导航

- 大纲基于文档 `h1`–`h6` 标题自动生成层级结构，默认仅展开一级目录。
- 当前阅读章节自动高亮；跳转章节时，其上级目录将自动展开。
- 支持一键全部展开 / 全部收起；切换文档后不会携带旧文档的折叠状态。
- 大纲同时用于章节跳转、PDF 书签生成与阅读位置恢复。

> [!NOTE]
> **场景示例**：阅读长篇 README 文档时，先点击「安装」章节，再点击「配置」章节；大纲高亮会跟随正文滚动同步更新，无需手动定位。

### 3.2 全文搜索

- 通过 `Ctrl+F` 或 `Ctrl+K` 唤起搜索面板。
- 默认搜索当前书库内全部文档，也可切换为仅搜索当前文档。
- 支持中文单字、双字词精准匹配；三字及以上关键词将调用全文索引加速检索。
- 搜索结果展示所属文档、对应章节与命中片段；点击结果直接跳转，`F3` / `Shift+F3` 可在多处命中之间循环切换。
- 按 `Esc` 关闭搜索面板并清除关键词高亮。

> [!NOTE]
> **场景示例**：搜索关键词 `task_parts`，从结果列表直接跳转到「任务清单」章节；再按 `F3` 快速查看下一处命中位置。

### 3.3 阅读进度与恢复

- 每篇文档独立保存阅读位置，互不干扰。
- 位置恢复优先采用「章节 + 章节内源码行偏移」的计算方式，布局变动时定位更稳定。
- 设置项「启动时恢复上次文档」默认开启；关闭后冷启动直接进入空白界面，启动速度更快。
- 页面刷新或 WebView 重载时，Folio 会自动恢复当前文档，不会误判为冷启动。

## 4. 编辑：内容修改、任务清单与保存机制

阅读态与编辑态共享同一份文档。理解两者的边界，尤其是任务勾选何时真正写入磁盘，可以避免误操作。

### 4.1 阅读 / 编辑模式切换

- 按 `Ctrl+E` 可在阅读模式与编辑模式间一键切换。
- 编辑区基于 CodeMirror 实现，支持语法高亮、行号显示、代码折叠与软换行。
- `Tab` 键插入制表符；选中多行后按 `Tab` / `Shift+Tab` 可整块缩进 / 反缩进。
- 按 `Ctrl+M` 可将焦点切回导航区域。
- 存在未保存修改时，页签将显示脏标记；关闭页签、切换文档或退出程序前会弹出保存确认。

### 4.2 任务清单：勾选后需手动保存

阅读模式下可直接点击任务复选框。勾选操作仅修改内存状态并标记为未保存，**不会立即写入磁盘**；确认修改后需按 `Ctrl+S` 完成落盘。

```markdown
- [ ] 撰写发布说明
- [x] 完成回归测试
```

> [!IMPORTANT]
> 任务勾选只改内存，不自动写盘。若直接关闭或放弃修改，磁盘文件仍保持原样。

> [!NOTE]
> **场景示例**：阅读项目 README 时勾选「撰写发布说明」，左下角将出现未保存状态提示；按 `Ctrl+S` 保存后，用记事本打开源文件可看到 `[ ]` 已自动变为 `[x]`。若选择放弃修改，磁盘文件内容将保持不变。

### 4.3 保存、放弃与文件冲突

- `Ctrl+S` 保存当前文档；阅读模式下的待存勾选状态会同步写入文件。
- 放弃保存将还原内存内容至磁盘最新状态，并清除脏标记。
- 保存前会校验文件修改时间；若外部程序修改了同一文件，将弹出提示，可选择重新加载或覆盖保存。
- 保存完成后，将自动同步更新搜索索引、文档大纲与统计信息。

## 5. 插入：右键模板、标注块与 Emoji

编辑区的右键菜单把常用 Markdown 结构做成可点选模板，不需要记忆语法即可插入表格、代码块、任务清单、标注块和表情。

### 5.1 编辑区右键菜单

在编辑区点击右键，可快速插入常用 Markdown 结构：

| 分类 | 可插入内容 |
| :--- | :--- |
| 行内元素 | 粗体、斜体、删除线、行内代码、链接 |
| 列表结构 | 无序列表、有序列表、任务清单；支持连续点击追加 |
| 块级元素 | 引用、表格、标题、代码块、标注块、图片、链接、分隔线 |
| 表情符号 | Emoji 分组选择面板 |

补充说明：

- 表格支持通过「列 × 行」可视化格盘选择尺寸。
- 代码块按语言分组：通用、前端、后端、数据、脚本、图表、其他。
- 列表自动续号并保持缩进一致；表格、代码块、标注块与分隔线会自动补充前后空行。
- 每次插入操作支持 `Ctrl+Z` 整体撤销；仅修改编辑区内容，不会自动保存到文件。

### 5.2 标注块（Callout）

右键选择「标注块」，可插入五种 GitHub 风格提示块。语法示例：

```markdown
> [!NOTE]
> 这是一条补充说明。

> [!WARNING]
> 这里需要特别注意。
```

支持的类型与用途：

| 类型标识 | 适用场景 |
| :--- | :--- |
| `NOTE` | 提示说明、补充信息 |
| `TIP` | 使用技巧、优化建议 |
| `IMPORTANT` | 关键信息、重要须知 |
| `WARNING` | 风险提示、注意事项 |
| `CAUTION` | 高危操作、严重警告 |

已有选区内插入标注块，会将选中行整体转为引用格式并在顶部添加类型行；空光标位置插入将生成一个空白模板。

### 5.3 Emoji 表情

右键选择「Emoji 表情」打开面板：

- 按「状态与标记 / 表情与情绪 / 手势与人物 / 开发与文档常备 / 箭头与分隔」分为 5 组，内置 57 个常用表情。
- 右上角可切换插入格式：
  - 短代码格式：`:rocket:`
  - Unicode 格式：`🚀`
- 鼠标悬停可查看短代码名称与适用场景。

短代码在阅读窗会自动渲染为对应表情，示例：

```text
发布状态：:white_check_mark: 已通过
```

### 5.4 代码块语言支持

- 代码块显示语言标签与一键复制按钮。
- 语言面板分为 7 组、覆盖 24 种常用语言；也支持选择「无语言」或纯文本模式。

反引号围栏写法示例：

```js
const answer = 42;
console.log(answer);
```

波浪号围栏写法等价：

````markdown
~~~js
const x = 1;
~~~
````

## 6. 整理：源码格式化与目录树重命名

本章介绍如何让源码排版更整齐，以及在目录树中安全地重命名文件或文件夹。

### 6.1 源码自动格式化

通过「文档」菜单选择「源码自动格式化」，或按快捷键 `Shift+Alt+F` 执行。

格式化将执行以下处理：

- 为标题、列表、任务项、引用补全缺失的空格。
- 将连续空行压缩为单行；清理表格单元格首尾空白。
- 表头与分隔行列数不匹配时，按普通文本处理，避免误吞后续标题或列表。
- 代码块语言名统一转为小写；未闭合的代码围栏在文末自动补齐。
- 代码块内部、缩进代码、公式块、HTML 块与文件头部 front matter 保持原样不动。
- 未闭合的 `$$` 公式仅做提示，不会自动猜测闭合位置。

格式化前后对比示例：

```markdown
##标题
-item
- [x]done
>quote
```

格式化后：

```markdown
## 标题
- item
- [x] done
> quote
```

> [!WARNING]
> 格式化仅修改编辑区内容，不会自动写入磁盘；可通过 `Ctrl+Z` 整体撤销，确认无误后再按 `Ctrl+S` 保存。在阅读模式下执行格式化会自动切换到编辑态，方便查看与撤销。

### 6.2 目录树重命名

- 在目录树中右键文件 / 文件夹，或选中后按 `F2`，即可进入就地重命名。
- 文件默认选中主文件名，文件夹默认选中完整名称。
- 按 `Enter` 或点击其他区域提交修改；按 `Esc` 取消重命名。
- 自动校验名称合法性：包括空名称、非法字符、结尾字符、长度、扩展名、重名与目录存在性。
- 重命名生效后，将同步更新磁盘文件、目录树、页签、最近打开记录、搜索索引与阅读进度。

> [!NOTE]
> **场景示例**：将 `notes\old.md` 重命名为 `notes\release.md`，已打开的对应页签会自动同步新路径，无需重新打开；若取消或重命名失败，原文件名保持不变。

## 7. 外观：主题、排版与软换行设置

点击标题栏设置按钮，或通过「查看」菜单进入设置面板。设置共分为五组：

| 分组 | 可调节项 |
| :--- | :--- |
| 外观 | 主题、强调色、启动时恢复上次文档 |
| 字体 | 衬线 / 无衬线字体、正文字号 |
| 段落 | 行高、字距、段落间距、对齐方式、段落内换行 |
| 版面 | 页面最大宽度 |
| 代码与表格 | 代码字号、表格密度 |

补充说明：

- 内置深色、浅色、护眼米色三套主题。
- 提供十二种强调色，在日夜主题下自动适配对应色阶。
- 所有设置即时生效并自动保存；支持配置导入、导出、放弃更改与恢复默认。

### 7.1 段落内换行显示开关

该开关默认关闭，遵循 GFM/CommonMark 规范：段落内单个换行符将被折叠为一个空格。

例如源码：

```text
第一行
第二行
```

默认显示效果：

```text
第一行 第二行
```

开启「段落内换行显示为换行」后，显示效果为：

```text
第一行
第二行
```

注意事项：

- 该开关仅影响显示效果，不会修改源文件内容。
- HTML / PDF 导出效果将跟随该开关设置。
- 纯图片行、徽章类段落不受影响，始终保持横排；宽度超出时自动折行。

## 8. 导出：HTML 与 PDF 输出

Folio 可以把当前文档导出为可独立分发的 HTML 或 PDF，图片、表格、脚注和标题书签会尽量按阅读窗效果保留。

### 8.1 HTML 导出

- 将当前文档导出为内置精简样式的独立 HTML 文件。
- 正文引用的本地图片将复制到同级 `images/` 目录；远程图片将自动下载。
- 导出的 HTML 文件不依赖 Folio，可直接在浏览器中打开。
- 软换行设置、表格换行与对齐、脚注、图片行效果均与阅读窗保持一致。

### 8.2 PDF 导出

- 将当前阅读视图导出为 A4 尺寸 PDF 文件。
- 页边距设置：上下 15mm，左右 12mm。
- 页面底色跟随当前主题，不会出现固定黑色边框。
- 标题栏、侧边栏、状态栏与悬浮层不会被导出到 PDF 中。
- 折叠状态的标注块在打印时会自动展开。
- 文档 `h1`–`h6` 标题将自动生成 PDF 大纲书签。
- 长文档导出前会等待正文与图表渲染完成，避免导出内容不完整。
- 图片行、徽章段在 PDF 中保持横排；表格换行与对齐格式完整保留。

> [!NOTE]
> PDF 阅读器在书签前显示的图标为阅读器自带界面元素，不属于 Folio 导出的文档内容。

## 9. Markdown 语法规范与示例

Folio 以 GFM 0.29-gfm 规范为渲染基线，GitHub README、技术文档与普通笔记均可直接正常阅读。

> [!TIP]
> 本章示例中的围栏代码块用于展示写法。若示例本身又包含代码围栏，会使用更长的外层围栏，避免提前闭合。

### 9.1 标题、列表与任务

```markdown
# 一级标题

## 二级标题

- 无序列表项
- 另一个无序列表项

1. 有序列表项
2. 另一个有序列表项

- [ ] 未完成任务
- [x] 已完成任务
```

嵌套有序列表支持层级编号显示：

```markdown
1. 第一章
   1. 第一节
   2. 第二节
2. 第二章
```

阅读窗可显示为 `2.1`、`2.2` 这类父级链路编号；字面写法 `2.1.` 不会被识别为列表标记。

### 9.2 表格：对齐与单元格换行

```markdown
| 左对齐 | 居中 | 右对齐 |
|:---|:---:|---:|
| A | B | C |
| 第一行<br>第二行 | 说明 | 123 |
```

- `:---` 代表左对齐，`:---:` 代表居中，`---:` 代表右对齐。
- 表格单元格内的 `<br>` 会渲染为真实换行。
- 表头与分隔行列数不一致时，不会按表格解析。

### 9.3 代码块

````markdown
```js
const answer = 42;
console.log(answer);
```
````

波浪号围栏写法同样支持：

````markdown
~~~text
plain text block
~~~
````

代码块支持语言标签、语法高亮与一键复制；代码内部的 Markdown 语法不会被二次解析。

### 9.4 链接与引用定义

行内链接：

```markdown
[Folio 项目](https://github.com/liumeice/Folio)
```

引用式链接：

```markdown
[Folio 项目][folio]

[folio]: https://github.com/liumeice/Folio
```

最后一行为链接引用定义，阅读窗不会直接显示，仅用于为上方引用提供链接地址。如果定义行被渲染为正文，通常是因为前方缺少空行、被缩进为代码块，或格式不符合规范。

### 9.5 脚注

```markdown
Folio 支持脚注[^1]。

[^1]: 这是脚注的具体内容。
```

阅读窗会将 `[^1]` 渲染为上标，脚注定义汇总到文档末尾，并提供 `↩` 回跳链接；回跳锚点与脚注正文保持同行。

### 9.6 Front matter

仅放置在文件最开头时生效：

```yaml
---
title: 示例文档
tags: [gfm, folio]
---
```

阅读窗将渲染为元信息卡片；放置在正文中间不会触发 front matter 解析。

### 9.7 图片与图片行

```markdown
![单图](images/single.png)

![徽章 A](images/a.svg)
![徽章 B](images/b.svg)
```

- 单张图片默认居中显示。
- 连续多张图片自动形成图片行，保持横向排列；超出宽度时自动折行。
- 图片行不受「段落内换行显示为换行」开关影响。

### 9.8 硬换行与软换行

硬换行（强制换行）：

```text
第一行  
第二行
```

第一行末尾带有两个空格，阅读窗将显示为两行。

```text
第一行\
第二行
```

行尾反斜杠同样会产生硬换行。

软换行（普通换行）：

```text
第一行
第二行
```

默认折叠为一个空格；开启「段落内换行显示为换行」后将渲染为两行。

### 9.9 HTML 注释与安全标签

```html
<!-- 这是注释，阅读窗不显示 -->
```

- HTML 注释块不会在阅读窗显示。
- 原始 HTML 会经过安全净化；脚本、危险属性与不受支持的标签不会被执行。
- `script`、`iframe`、`style`、`textarea` 等标签将按标签过滤规则处理，显示为可见文本或直接拦截。

## 11. 常见问题与本地数据说明

先看高频疑问；本地数据位置、备份方式和恢复边界也放在本章。

### 11.1 为什么链接定义行没有显示？

这是正常现象。以下行属于链接引用定义，本身不会在阅读窗渲染：

```text
[01]: https://example.com
[02]: images/a.png
```

它们的作用是为 `[文字][01]` 这类引用式链接提供地址。如果定义行被显示为正文，请检查是否被缩进、前方是否缺少空行，或存在反斜杠转义。

### 11.2 勾选任务后，源文件为什么没有变化？

Folio 的任务勾选仅先修改内存状态并标记脏数据，需要按 `Ctrl+S` 才会写入磁盘。该设计用于避免误触直接修改文件。

### 11.3 为什么段落里的换行有时会被合并？

默认遵循 GFM/CommonMark 规范，段落内单个换行符会折叠为一个空格。开启「段落内换行显示为换行」后即可逐行显示。

### 11.4 PDF 书签前的图标可以去掉吗？

该图标由 PDF 阅读器自行绘制，不属于 Folio 导出的文档内容，无法通过 Markdown 或导出参数统一移除。

### 11.5 本地数据存储位置

Windows 系统下默认路径：

```text
%APPDATA%\app.folio.desktop\folio.db
```

同目录下还包含 `folio.db-wal`、`folio.db-shm`、`drafts\`、`guide.md` 与 `welcome.md` 等文件。备份数据时请先关闭 Folio，再将 `folio.db`、`folio.db-wal` 和 `folio.db-shm` 一并复制。

> [!TIP]
> 备份前先退出 Folio，避免数据库仍在写入时复制出不完整的文件。

### 11.6 刷新或崩溃后为什么只恢复了当前文档？

Folio 会自动恢复历史最近的一篇文档与阅读位置，但暂不支持恢复全部页签，这是当前版本的产品边界。阅读模式下未保存的任务勾选在刷新 / 崩溃后可能丢失，重要修改请及时保存。

## 12. 三个实战上手练习

用三个小练习把「阅读 → 修改 → 继续阅读」的完整流程串起来。

### 12.1 练习 1：浏览项目 README

1. 打开项目所在文件夹。
2. 点击左侧大纲，在「安装」与「配置」章节间跳转。
3. 按 `Ctrl+F` 搜索关键词 `API`，用 `F3` 切换不同命中位置。
4. 打开设置面板，切换深色 / 浅色主题，观察阅读区效果变化。

### 12.2 练习 2：整理会议记录

1. 打开一份会议记录文档，按 `Ctrl+E` 进入编辑模式。
2. 通过右键菜单插入任务列表，填写行动项。
3. 切回阅读模式，勾选已完成项，按 `Ctrl+S` 保存。
4. 按 `Shift+Alt+F` 一键格式化文档中的标题、列表与引用格式。

### 12.3 练习 3：制作可分享的接口说明

1. 使用右键菜单插入表格、代码块与标注块。
2. 表格使用 `:---:` 设置居中，单元格内用 `<br>` 实现换行。
3. 为重要参数添加 `> [!IMPORTANT]` 标注块提示。
4. 从「文件」菜单导出 HTML 与 PDF，检查图片、书签与表格格式是否完整。

---

先把「阅读」的基础流程用顺畅，再逐步掌握编辑、整理与导出能力。Folio 并非要替代所有专业写作工具，而是致力于让本地 Markdown 文档的「阅读 → 修改 → 继续阅读」全流程保持自然连贯。
