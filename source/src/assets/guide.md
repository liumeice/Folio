# Folio 使用指南

适用版本：`v0.2.1`

Folio 是一个 Windows 桌面本地 Markdown 阅读器：打开一个文件夹，就可以把里面的 `.md` 当成一本书来读。它重点解决四件事：读得舒服、找得到、记得住读到哪、需要时能顺手改。

> 本篇是 Folio 内置文档，首次运行时解出到应用数据目录。它不列入文件夹目录树，只出现在「最近打开」；和任何普通文档一样可以阅读、编辑与搜索。

## 1. 先分清两个入口

左侧有两个入口，它们负责不同的事情：

### 打开文件夹

用于按目录阅读。

- 选择“打开文件夹”后，Folio 会扫描该文件夹及其子目录中的 Markdown。
- 左侧显示文件夹目录树，可以按层级浏览文档。
- 同一时间只保留一个打开的文件夹；再次打开新文件夹会替换旧的。
- 打开文件夹不会修改或移动磁盘上的源文件。

### 最近打开

用于快速回到刚刚读过的文档。

- 无论是从目录树打开、单独打开文件，还是通过文档链接打开，都会留下记录。
- 按打开时间倒序排列，并按今天、昨天、日期分组。
- 单独打开一个文件只会进入“最近打开”，不会自动加入当前文件夹目录树。
- 保存文档不会改变它是否属于当前打开的文件夹。

举例：先打开 `D:\notes`，左侧会显示其中的文档；之后再单独打开 `D:\tmp\a.md`，它只会出现在“最近打开”，不会出现在 `D:\notes` 的目录树里。

## 2. 打开与阅读

### 打开文档

- 把 `.md` 文件拖进窗口即可阅读。
- 按 `Ctrl+O` 可以多选 `.md`、`.markdown`、`.txt`。
- 拖入文件夹，或在菜单里选择“打开文件夹…”，可以按目录阅读。
- 双击系统中的 Markdown 文件，也可以交给 Folio 打开。

### 多页签

- 打开多篇文档时，会在标题栏形成多个页签。
- 再次打开同一路径，只会激活已有页签，不会重复打开。
- 关闭页签不会删除磁盘文件，也不会删除最近打开记录。
- `Ctrl+W`、页签上的关闭按钮或鼠标中键都可以关闭当前页签。

### 阅读区字号

在阅读区按住 `Ctrl` 向上 / 向下滚动鼠标滚轮，可以放大 / 缩小正文字号。

- 只影响正文排版，标题栏、侧栏、菜单等应用界面不缩放。
- 字号与设置里的“正文字号”是同一项，会一起记住。
- 编辑模式与空态下不调整字号，也不会缩放界面。

### 文档链接

Folio 支持下面这种链接，可以直接打开某篇文档的某个章节：

```text
folio://open?doc=<文件标识>&sec=<标题文本>
```

例如：

```text
folio://open?doc=guide&sec=4. 全文搜索
```

在浏览器或其他程序里打开这类链接时，会唤起已经运行的 Folio，并定位到对应章节。

### 有序列表编号

阅读视图里，嵌套的有序列表自动继承父级序号：第 2 项下的子列表显示为 2.1、2.2，更深层级依此类推（1.1.1 这样）。这只是显示效果——源文件仍按标准写法（子列表照常从 `1.` 开始），保存的内容不变。

## 3. 大纲与阅读进度

### 大纲

左侧大纲根据 Markdown 的 `h1`–`h6` 自动生成：

- 标题按层级缩进，支持折叠：点箭头展开 / 收起，默认只展开第一层。
- 阅读滚动时只切换当前章节的高亮，不自动滚动大纲，也不自动展开分支。
- 当前章节位于收起的子树里时，高亮显示在最近可见的上级条目上。
- 点击条目跳转；跳转、搜索命中、位置恢复会展开目标分支，并把目标条目滚动到可见范围。
- 大纲右上角提供全部展开 / 全部收起。
- 键盘：`↑` / `↓` 移动，`←` 收起或回到父级，`→` 展开，`Enter` 或空格跳转。
- 文档保存后，大纲立即重建。

### 阅读进度

Folio 会为每篇文档单独记录阅读位置：

- 优先记住章节标题和章节内的位置。
- 标题改了、找不到原章节时，按整篇的百分比估算。
- 切换到其他文档再回来，仍从上次位置继续。
- 重启应用后，启动时回到最近打开的第一篇文档。

阅读区顶部有细进度条，状态栏显示阅读百分比。

## 4. 全文搜索

按 `Ctrl+F` 或 `Ctrl+K` 打开搜索。

- 可以跨文档搜索，范围是所有打开过的文档。
- 中文短词只有一两个字也能搜到。
- 结果按文档和章节分组，点击即跳转。
- 命中文字会高亮，结果多于一处时显示命中数量。
- 跳转后可用 `Enter` / `F3` 下一处、`Shift+F3` 上一处。
- `Esc` 清除高亮并关闭搜索浮条。

## 5. 编辑与任务清单

按 `Ctrl+E` 在阅读和编辑之间切换。

- 编辑器支持 Markdown 高亮、行号、折叠和自动换行。
- `Ctrl+S` 保存并回到阅读视图。
- 有未保存修改时，页签会显示未保存标记。
- 切换文档或关闭窗口前，会先确认未保存内容怎么处理。
- 阅读视图中的任务清单可以直接点击勾选；按 `Ctrl+S` 保存后写入文件。
- 保存后搜索结果和大纲会同步更新。

### 编辑区右键插入模板

在编辑区点击右键，可快速插入常用 Markdown 结构：

- 顶部图标条：剪切、复制、粘贴、删除所选、全选；没有选区时剪切 / 复制 / 删除置灰。
- 格式条：选中文字后可加粗、斜体、行内代码、删除线、链接；没有选区时置灰。
- 块级：无序 / 有序 / 任务列表（可连续点击追加，菜单保持展开）、引用、表格（先选列数和行数）、标题级别、代码块语言分组面板、标注块（`> [!NOTE]` 等五类 GitHub 提示块）、图片、链接、分隔线。
- 有选区时点标注块：选中各行整体转为引用并在上方加类型行，阅读视图按对应配色渲染提示块；空光标则插入一个空的标注块。
- Emoji 表情：面板按「状态与标记 / 表情与情绪 / 手势与人物 / 开发与文档常备 / 箭头与分隔」分组；右上角可切换插入制式——短代码（`:smile:`）或直接插 Unicode 表情字符，鼠标悬停每个表情会显示其短代码与适用场景。
- 列表自动续号并沿用缩进；表格 / 代码块 / 标注块 / 分隔线自动补前后空行；插入后光标落在应填内容的位置。
- 每次插入后按一次 `Ctrl+Z` 可整体撤销；只改编辑区内容，不会自动保存到文件。

### 源码自动格式化

从“文档”菜单选择“源码自动格式化”，或按 `Shift+Alt+F`：

- 补齐标题、列表、任务清单和引用标记后缺少的空格；
- 连续空行压到一行，清理表格单元格首尾空白；表头与分隔行列数对不上时按普通文本处理，表格后面的标题、引用、列表不会被误当表格行改动；
- 代码块开头的语言名统一改成小写；没有闭合的代码块在文末补齐；
- 代码块内部、公式块、HTML 块和文件头部的元信息原样保留，不重排段落与表格列宽。多行 HTML 块（`<script>`、`<pre>`、`<!--` 注释等）一直保护到各自的闭合标记，中间的空白行不会中断保护；
- 只处理顶层结构：引用标记之后、列表项之内的嵌套内容保持原样（如 `> ##标题` 不会补空格）；
- 公式块 `$$` 没有闭合时只提示、不猜测闭合位置，其后内容原样保留。

格式化只改编辑区内容，不会自动保存到文件；改动可以按 `Ctrl+Z` 整体撤销，确认后再按 `Ctrl+S` 保存。阅读模式下格式化会先进入编辑模式，以便查看结果和撤销。

## 6. 外观与设置

点击标题栏的设置按钮，或从“查看”菜单进入设置。

可以调整：

- 主题：深色、浅色、护眼米色。
- 强调色：十二种，深色和浅色主题下都看得清。
- 字体族、正文字号。
- 行高、字距、段落间距、对齐方式。
- 页面最大宽度。
- 代码字号和表格密度。

设置会立即生效并保存，下次打开仍然保留。还支持导入、导出设置、撤销更改和恢复默认。

## 7. 导出

### 导出 HTML

把当前文档导出为带精简样式的 HTML，并把正文图片放到同级 `images/` 目录：本地图片从磁盘复制，网络图片由 Folio 下载。导出的 HTML 不依赖 Folio 即可打开。

### 导出 PDF

把当前阅读视图导出为 A4 PDF：

- 页边距为上下 15mm、左右 12mm。
- 页面底色跟随当前主题，不再出现固定黑色边框。
- 标题栏、侧栏、状态栏和浮层不会进入 PDF。
- 折叠的提示块在打印时展开。
- `h1`–`h6` 会生成 PDF 大纲书签。
- 长文档导出前会等正文和图表都显示完，避免只导出半截。

> PDF 阅读器可能在书签前显示自己的书签图标，那是阅读器界面，不是文档内容。

## 8. 常用快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl+N` | 新建文档 |
| `Ctrl+O` | 打开文档 |
| `Ctrl+F` / `Ctrl+K` | 全文搜索 |
| `Ctrl+E` | 切换阅读 / 编辑 |
| `Ctrl+S` | 保存编辑 |
| `Ctrl+滚轮` | 阅读区正文字号放大 / 缩小 |
| `Shift+Alt+F` | 源码自动格式化 |
| `Ctrl+W` | 关闭当前页签 |
| `Ctrl+Q` | 退出 Folio |
| `Alt+↑` / `Alt+↓` | 上一章 / 下一章 |
| `Alt+←` / `Alt+→` | 后退 / 前进 |
| `Home` | 回到顶部 |
| `F3` / `Shift+F3` | 搜索命中下一处 / 上一处 |
| `Esc` | 关闭弹层、清除高亮、退出专注或放弃编辑 |

## 9. 用了哪些技术

- 桌面外壳：Tauri 2（WebView2）
- 程序本体：Rust
- 本地数据：SQLite（保存阅读记录与全文搜索）
- 界面：SolidJS + TypeScript + Vite
- 编辑器：CodeMirror 6

## 10. 现在可以试试

- 点击左侧大纲，跳到任意章节。
- 按 `Ctrl+F` 搜索“大纲”，再用 `Enter` 循环命中。
- 按 `Ctrl+E` 改一个字，再按 `Ctrl+S` 保存。
- 在任意文档的任务清单里勾选一项，按 `Ctrl+S` 后再打开源文件，看看是否已经写入。
- 打开设置，切换主题或强调色，看看阅读区如何变化。
