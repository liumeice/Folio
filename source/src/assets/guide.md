# Folio 使用指南

> 浏览器回退层（无 Rust 环境时）的演示文档；正式版中本指南以真实 .md 提供。

## 1. 核心概念

- **文档库**：用「文件 → 打开文件夹…」登记的目录，其中的文档按**目录层级**显示（正式版存 SQLite）。单独打开一个文件不会进库；**同时只保留一个库**，选新目录就是切换（旧库文档转为「仅最近打开」，磁盘与进度不动）。
- **最近打开**：你打开过的文件历史，左侧独立面板，不限量保留；随时可单条移除或整体清空——那都不碰库、不碰磁盘。
- **大纲**：h1~h6 自动生成，滚动联动高亮
- **进度记忆**：每文档独立的 标题锚点 + 段内偏移 + 比例兜底
- **排版设置**：右侧抽屉，控件区间固定（字级 12.5–19.5、行高 1.4–2.4、字距 0–0.12em、段距 0.6–2em、行宽 640–1280px、代码 10.5–15.5px），改完立刻生效并持久化

## 2. 快捷键

| 键 | 功能 |
| --- | --- |
| `Ctrl+O` | 打开文档 |
| `Ctrl+F` | 搜索（F3 命中循环） |
| `Ctrl+E` | 编辑模式（`Ctrl+S` 保存 / `Esc` 放弃） |
| 滑杆按钮（标题栏） | 排版设置抽屉：字级 / 行高 / 字距 / 段距 / 对齐 / 行宽 / 代码字号 / 表格密度，带样张与恢复默认 |
| `Alt+↑/↓` | 上一章 / 下一章 |
| `Alt+←/→` | 后退 / 前进 |

## 3. 阅读

拖拽打开、任务清单勾选、深链 `folio://open?doc=<slug>&sec=<标题>` 均为正式版能力；
浏览器模式下以内存模拟，功能行为一致。
